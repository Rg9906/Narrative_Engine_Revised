# Specification: Contextual Lookback

**Track ID:** contextual-lookback_20260816
**Type:** Feature
**Created:** 2026-08-16
**Status:** Complete

## Summary

Named in `master_context_summary.md`'s "Potential Extensions": expand the
State Engine to recall the previous chapter's raw text alongside the
global narrative state, so LLM extraction stages have direct continuity
across a chapter break (a scene spanning two chapters, a line of dialogue
picked back up) that structured state fields alone don't capture.

## Acceptance Criteria

- [x] `NarrativeState` gains `previous_chapter_excerpt: str` and
      `previous_chapter_number: Optional[int]`, serialized under
      `metadata` in `to_dict()`/`from_dict()`, defaulting gracefully
      (`""` / `None`) when absent from older `narrative_state.json` files.
- [x] `src/main.py::process_chapter` records the tail (last 1500 chars) of
      each chapter's raw text into `state.previous_chapter_excerpt` /
      `previous_chapter_number` *after* that chapter's delta is applied —
      so `ContextRetriever`'s call earlier in the same `process_chapter`
      run (inside `Pipeline.process_chapter`) still sees the *previous*
      chapter's excerpt, not the one just processed.
- [x] `ContextRetriever` threads the excerpt through
      `_load_data_sources`/`_extract_sources` and renders it as a new,
      unconditional `<PreviousChapterExcerpt>` tier (fixed-size, not
      contested against the byte-budget tiers B/C/E) when present, omitted
      entirely when absent.
- [x] No regressions: full suite green, old-format `narrative_state.json`
      (no `previous_chapter_excerpt` key) loads and serves context
      correctly with the tier simply omitted.

## Out of Scope

- Multi-chapter lookback (only the immediately preceding chapter, per the
  vision doc's wording — "the previous chapter's raw text").
- Any change to how much of the excerpt an LLM extraction stage actually
  uses/weighs — this only makes the data available in the context block.

## Technical Notes

Verified against the real, committed `data/memory/narrative_state.json`
(4-chapter dataset): loads with `previous_chapter_excerpt=""` (never set
by any prior run, expected), and a synthetic excerpt correctly appears in
a real `ContextRetriever.retrieve_context()` call against that state.
